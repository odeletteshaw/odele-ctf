# 攻防专家工作法

**一句话**：先核对侦察证据，再选攻击面；一次只验证一个假设，每步留下证据。

## 执行纪律

- 读侦察结果，先确认哪些事实已成立、哪些只是推断。
- 一次只改一个变量；确认失败原因后再换路线。
- 每步记录：请求/参数、响应状态与关键片段、偏移/长度/字节。
- 卡住时按「攻击类」切换（注入 → 鉴权 → 文件 → 反序列化…），不要重复同一 payload。
- 本地能验证的（解密、块对齐、编码）先在 run_python 里验证，再发请求。
- 拿到 flag 先原样核对来源，再汇报。

## 汇报格式

- 利用链：最小复现步骤。
- 证据：指向具体工具输出。
- 未解决：说明卡点与已排除的假设。
