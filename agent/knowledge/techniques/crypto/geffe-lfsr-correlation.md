# LFSR 流密码：Geffe 生成器相关攻击 + GF(2) 线性恢复

**一句话**：多个 LFSR + 非线性合并函数生成密钥流时，先化简合并函数找「输出对某个输入的概率相关性」（Geffe 是 3/4），再逐个 LFSR 相关攻击恢复，最后一个用 GF(2) 高斯消元从已知比特线性解出。

## 触发信号

- 附件里有 LFSR 定义（`fpoly` 抽头）+ 一个非线性合并函数，如 `iv = (a&b) ^ (b&c) ^ c`。
- 有一段已知明文对应的密文，或一段已知的密钥流比特。
- 题面 / 类名提到 stream cipher、keystream、LFSR、Geffe。

## 核心套路

1. **化简合并函数找相关性**：`(a&b)^(b&c)^c = (a&b)^(c&~b)`——b=1 时输出 a，b=0 时输出 c，所以输出对 a 和 c 都有 **3/4 相关性**。
2. **逐个 LFSR 相关攻击**：对每个 LFSR，枚举全部 2^n 初态，生成同样长度的流，统计与观测流的逐位匹配数。正确状态 ≈ 3/4（如 240/320），随机状态 ≈ 1/2（160/320），差 10σ 以上，无歧义。
3. **GF(2) 恢复最后一个**：把合并函数真值表展开，找出「某个 LFSR 的输出位被确定」的位置（如 Geffe 里 a≠c 时 b 被确定），对 b 的已知位建线性方程组（b 是 L2 初态的线性函数），高斯消元解出初态。
4. **重组**：三个 LFSR 恢复后，任意长度密钥流都能生成，直接解密。

## 坑

- **双输出约定取全局最高分**：LFSR 有「最高位输出+左移」和「最低位输出+右移」两套约定，相关攻击两套都扫、取全局最优；别「首个过阈值就定」，弱命中会覆盖强命中。
- **转置动力学（最隐蔽）**：GF(2) 恢复时，线性泛函（行向量）按 `r' = (r>>1) ^ (tap·r[0])` 演化，**不是**状态自身的演化。用错演化会得到「消元秩满、零矛盾、但回代验证 83/155」的假一致解——**永远回代验证**。
- **相关性来自合并函数，不是 LFSR 本身**：先化简合并函数，别上来硬破解。
- 若流密码还配了一个分组密码（如自制 SPN + CBC），先单独恢复那个分组密码的密钥，再做流密码的关联攻击。
