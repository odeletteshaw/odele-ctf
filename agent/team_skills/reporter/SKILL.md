# 复盘报告模板

**一句话**：写清「谁做了什么、看到了什么、为什么成/败」，让下一次能直接复用。

## 结构

1. **题目与目标**：方向、入口、要拿的东西。
2. **团队分工与执行**：团队长计划 → 侦察发现 → 专家尝试（按时间顺序）。
3. **关键发现与利用链**：最小复现步骤，附证据（请求/响应/偏移/输出片段）。
4. **成败原因**：成功的关键判断；失败卡点与当时的错误假设。
5. **最终 flag**：原样引用；未拿到就写未拿到。

## 原则

- 只写真实发生的内容，不编造。
- 证据优先于形容词；引用具体的请求、参数、响应片段。
- 300-500 字；失败复盘同样有价值。
